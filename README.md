# Поле чудес

Аркадный футбол 5 на 5 в дворовой коробке. Чистая статика: HTML, CSS и
несколько файлов JavaScript, без сборки. Работает как PWA, живёт на
GitHub Pages: https://zyablikovalex-art.github.io/congenial-happiness/

## Из чего состоит

| файл | за что отвечает |
|---|---|
| `game.js` | симуляция: мир, физика, ИИ, ввод, меню, сеть |
| `scene.js` | только отрисовка (Three.js), ничего не решает |
| `physics.js` | все настраиваемые числа физики, с расшифровкой в метрах |
| `net.js` | транспорт для игры по сети |
| `sw.js` | service worker, офлайновый кэш |

## Версия релиза

Номер версии один на всю игру и **увеличивается на каждый релиз**. Держать
одинаковым в двух местах:

- `game.js` — `const APP_VERSION = N`, показывается в углу меню;
- `sw.js` — `const CACHE = "mini-football-vN"`, по нему обновляется кэш.

Если поднять только `APP_VERSION`, игрок увидит новый номер поверх старых
закэшированных файлов. Если только `CACHE` — номер в меню соврёт.

## Масштаб мира

Модель игрока — 86.7 мировых единиц от земли до макушки, это «185 см».
Значит **1 метр = 46.86 единиц**, одна единица = 2.13 см. Все размеры
площадки и все числа в `physics.js` посчитаны по этому курсу.
